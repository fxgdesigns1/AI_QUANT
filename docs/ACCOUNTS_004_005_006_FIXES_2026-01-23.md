## Fixes Applied

### Fix 1: Improved Strategy Registry Lookup (Accounts 004, 005)

**File:** `working_trading_system.py` (lines 1042-1063)

**Changes:**
- Enhanced strategy info lookup with proper alias resolution
- Added fallback to direct registry lookup if `get_strategy_info()` fails
- Improved error handling and logging
- Ensures `resolve_strategy_alias()` is called before lookup

**Before:**
```python
try:
    strategy_info = get_strategy_info(strategy_key)
except Exception:
    strategy_info = get_strategy_registry().get(strategy_key)
```

**After:**
```python
from src.control_plane.strategy_registry import get_strategy_info, resolve_strategy_alias
# Try with alias resolution first
resolved_key = resolve_strategy_alias(strategy_key)
strategy_info = get_strategy_info(resolved_key)

# If that fails, try direct lookup
if not strategy_info:
    from src.control_plane.strategy_registry import get_strategy_registry
    registry = get_strategy_registry()
    strategy_info = registry.get(resolved_key) or registry.get(strategy_key)
```

**Impact:** Accounts 004 and 005 should now properly resolve their strategy instruments from the registry.

### Fix 2: Relaxed Roadmap Alignment for Account 006

**File:** `src/strategies/session_execution_strategy.py` (lines 230-300)

**Changes:**
- **RELAXED** alignment requirements to allow trading when at least one timeframe is directional
- Changed from requiring BOTH daily AND weekly to be directional and matching
- Now allows trading when:
  - Weekly is directional (BULLISH/BEARISH) - preferred (longer-term view)
  - Daily is directional but weekly is NEUTRAL - allowed
  - Both are directional and match - ideal (strongest signal)
  - Both are directional but different - uses weekly bias (longer-term priority)
- Only blocks when BOTH are NEUTRAL (no clear direction)

**Before:**
- Required daily to be BULLISH or BEARISH (NEUTRAL blocked)
- Required weekly to be BULLISH or BEARISH (NEUTRAL blocked)
- Required daily and weekly to match exactly
- Result: 3,910 blocks from `roadmap_misaligned`

**After:**
- Priority 1: If weekly is directional, allow trading (use weekly bias)
- Priority 2: If daily is directional but weekly is NEUTRAL, allow trading (use daily bias)
- Only blocks if both are NEUTRAL

**Impact:** Account 006 should now trade much more frequently, as it only requires ONE timeframe to be directional instead of both.
